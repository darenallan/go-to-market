# Sanhia — stratégie go-to-market

Document stratégique interactif (une page HTML) présentant le plan de lancement de **Sanhia**, la marketplace de boutiques locales du Burkina Faso.

## Sections

Positionnement · profil client idéal (ICP) et personas · acquisition vendeurs et clients · réseaux sociaux, TikTok, WhatsApp · universités · influenceurs · parrainage.

## Lancer

Ouvrir `index.html` dans un navigateur.
